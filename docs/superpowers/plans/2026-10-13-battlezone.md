# Battlezone Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a browser version of Atari's 1980 Battlezone that renders at 1920x1080. It uses the arcade's own shapes, obstacle layout, font and HUD positions, and its rules and enemy behaviour, on a WebGL2 vector-CRT renderer.

**Architecture:** Game rules live in pure ES modules (`game.js`, `ai.js`, `world.js`) that advance a plain state object by `dt` seconds and return events. Rendering turns that state into a flat list of 2D line segments, and a WebGL2 pipeline draws them as glowing phosphor lines. A one-off extractor script parses the published ROM disassembly into `src/data/rom.js`, which is the only source of shapes, obstacles, font, reticles, radar, landscape and string positions.

**Tech Stack:** Vanilla JavaScript ES modules, WebGL2, Web Audio API and the Gamepad API. Node ≥ 20 for `node --test` and the extractor. No runtime dependencies, no bundler.

**Spec:** `docs/design.md` (decisions) and `docs/research.md` (facts). Read both before starting any task.

## Global Constraints

- No runtime dependencies and no build step. The browser loads `src/main.js` as an ES module from a static server: `python3 -m http.server 8080`. A `file://` URL will not load ES modules.
- The canvas backing store is fixed at 1920x1080. CSS scales it to fit the window and letterboxes it.
- 16:9 framing: vertical FOV 73.74° (focal length 720 px), horizontal FOV about 106°. The horizon is at screen center. HUD lines in the top 216 px are tinted red, everything else green.
- World units are ROM units ("u"); time is in seconds. ROM per-tick numbers are converted with `TICK = 15.625` ticks/s, and only in `src/config.js`.
- World coordinates wrap at ±32768 on both axes. Compute every distance and bearing with `delta()`/`dist()`/`bearing()` from `src/math.js`, never with raw subtraction.
- Angles are radians. Facing `0` = +z (toward the moon at game start). Positive = clockwise seen from above, i.e. turning right. Forward vector `(sin f, cos f)` in (x, z).
- `src/data/rom.js` is generated by `tools/extract-rom.mjs`. Never hand-edit it.
- Scoring: slow tank 1000, missile 2000, super tank 3000, saucer 5000. 3 lives. Bonus tanks at 15,000 and 100,000. Missiles from 10,000.
- Tests: `node --test` from the repo root. Each test file sits in `test/` and is named `*.test.js`.
- Every calibration constant (a value we could not take from the ROM) lives in `src/config.js` with a `ponytail:` comment naming what to calibrate against.

## Review Focus

These five inputs and conditions are implied by the spec, are most likely to hit a real player, and no feature test would otherwise exercise them. Each one has a pinned test or check in the task named.

1. **Tab switched away and back:** `requestAnimationFrame` resumes with a multi-second `dt`. Nothing should teleport through obstacles. `step()` clamps `dt` to 0.05 s (Task 3 test).
2. **Fighting across the world wrap seam:** an enemy at x=32000 and the player at x=-32000 are 1536 u apart, not 64000. Radar, messages and AI must agree (Task 2 test; Task 9 radar test).
3. **Respawn after death:** the player must never respawn inside an obstacle (Task 5 test). A spawned tank must not start inside one either (Task 4 test).
4. **Private browsing or corrupted `localStorage`:** high scores fall back to the defaults and the game keeps running (Task 11 test).
5. **Holding fire:** fires one shell, not a stream. Firing is edge-triggered (Task 6 test).

```js
// Parses Andy McFadden's annotated Battlezone (rev 2) disassembly into src/data/rom.js.
// Usage: node tools/extract-rom.mjs [saved-listing.html]   (fetches the listing when no file is given)
import { readFileSync, writeFileSync } from 'node:fs';
import { pathToFileURL } from 'node:url';

const LISTING_URL = 'https://6502disassembly.com/va-battlezone/Battlezone.html';
const TAU = Math.PI * 2;

const NAMES = {
  0x00: 'narrowPyramid', 0x01: 'tallBox', 0x02: 'tank', 0x03: 'shell', 0x0c: 'widePyramid',
  0x0d: 'radarDish', 0x0e: 'shellBurst', 0x0f: 'shortBox', 0x16: 'missile', 0x17: 'logoBa',
  0x1e: 'logoTtle', 0x1f: 'logoZone', 0x20: 'saucer', 0x21: 'superTank',
};
const shapeName = (id) =>
  NAMES[id] ?? (id <= 0x0b ? `tread${id - 4}` : id >= 0x24 ? `spatter${id - 0x24}` : `chunk${id.toString(16)}`);

export const toText = (html) =>
  html.replace(/<[^>]*>/g, '').replace(/&lt;/g, '<').replace(/&gt;/g, '>').replace(/&amp;/g, '&');

const hexOperands = (s) => (s.split(';')[0].match(/\$[0-9a-f]{2}\b/g) ?? []).map((h) => parseInt(h.slice(1), 16));

function parseAvg(op, rest) {
  const num = (k) => Number(rest.match(new RegExp(`${k}=([-+]?\\d+)`))?.[1] ?? 0);
  if (op === 'VCTR' || op === 'SVEC') return { op: 'draw', dx: num('dx'), dy: num('dy'), in: num('in'), len: op === 'VCTR' ? 4 : 2 };
  if (op === 'VJSR' || op === 'VJMP') return { op: op === 'VJSR' ? 'jsr' : 'jmp', target: parseInt(rest.match(/\(\$([0-9a-f]{4})\)/)[1], 16), len: 2 };
  if (op === 'VRTS' || op === 'HALT') return { op: 'rts', len: 2 };
  if (op === 'CNTR') return { op: 'center', len: 2 };
  return { op: 'nop', len: 2 }; // STAT, SCAL
}

// Returns { mem: Map<addr, byte>, avg: Map<addr, instr>, glyphs: {char, target}[], strings: {x,y,text}[] }.
export function parseListing(text) {
  const mem = new Map(), avg = new Map(), glyphs = [], strings = [];
  let cont = null, inEnglish = false;
  for (const line of text.split('\n')) {
    if (line.includes('str_addr_en')) inEnglish = true;
    if (line.includes('str_addr_fr')) inEnglish = false;
    const m = line.match(/^([0-9a-f]{4}): ((?:[0-9a-f]{2} )*[0-9a-f]{2})(\+?)/);
    if (m) {
      const addr = parseInt(m[1], 16);
      const bulk = line.match(/\.bulk\s+(.*)/);
      const bytes = m[3] === '+' && bulk ? hexOperands(bulk[1]) : m[2].split(' ').map((h) => parseInt(h, 16));
      bytes.forEach((b, i) => mem.set(addr + i, b));
      cont = m[3] === '+' ? addr + bytes.length : null;
      const ins = line.match(/;(VCTR|SVEC|VJSR|VJMP|VRTS|CNTR|STAT|SCAL|HALT)\b(.*)/);
      if (ins && addr < 0x4000) avg.set(addr, parseAvg(ins[1], ins[2]));
      const glyph = line.match(/;VJSR a=\$[0-9a-f]+ \(\$([0-9a-f]{4})\) '(.)'/);
      if (glyph) glyphs.push({ char: glyph[2], target: parseInt(glyph[1], 16) });
      const str = line.match(/;([-+]\d+),([-+]\d+) '(.*)'\s*$/);
      if (str && inEnglish) strings.push({ x: Number(str[1]), y: Number(str[2]), text: str[3].trim() });
      continue;
    }
    const more = line.match(/^\s+\+\s+(\$.*)/);
    if (more && cont !== null) {
      const bytes = hexOperands(more[1]);
      bytes.forEach((b, i) => mem.set(cont + i, b));
      cont += bytes.length;
    }
  }
  return { mem, avg, glyphs, strings };
}

const word = (mem, a) => mem.get(a) | (mem.get(a + 1) << 8);
const sword = (mem, a) => { const w = word(mem, a); return w & 0x8000 ? w - 0x10000 : w; };

// Shape `id`: vertex table at $388e, draw-command table at $7472 (both 44 little-endian pointers).
export function readShape(mem, id) {
  const va = word(mem, 0x388e + id * 2), ca = word(mem, 0x7472 + id * 2);
  if (!va || !ca || !mem.has(va) || !mem.has(ca)) return null;
  const verts = [];
  for (let i = 0; i < (mem.get(va) - 1) / 6; i++) {
    const p = va + 1 + i * 6;
    const [fwd, right, up] = [sword(mem, p), sword(mem, p + 2), sword(mem, p + 4)];
    verts.push([-right || 0, up, fwd]); // ROM shapes are mirrored left/right
  }
  const segs = [];
  let at = 0, inten = 0;
  for (let p = ca; mem.get(p) !== 0xff && mem.has(p); p++) {
    const b = mem.get(p), v = b >> 3, cmd = b & 7;
    if (cmd === 0) segs.push([v, v, inten]);
    else if (cmd === 1) inten = v;
    else if (cmd === 2 || cmd === 3) at = v;
    else if (cmd === 4) { segs.push([at, v, inten]); at = v; }
    // 5 = AVG projectile explosion (drawn procedurally), 6 = no-op
  }
  return { verts, segs };
}

// Interprets an AVG vector routine. Returns visible strokes [x0,y0,x1,y1,in] and the final beam position.
export function runAvg(avg, start) {
  const segs = [], stack = [];
  let x = 0, y = 0, pc = start;
  for (let guard = 0; guard < 10000; guard++) {
    const ins = avg.get(pc);
    if (!ins) throw new Error(`no AVG instruction at $${pc.toString(16)}`);
    if (ins.op === 'jsr') { stack.push(pc + ins.len); pc = ins.target; continue; }
    if (ins.op === 'jmp') { pc = ins.target; continue; }
    if (ins.op === 'rts') { if (!stack.length) return { segs, end: [x, y] }; pc = stack.pop(); continue; }
    if (ins.op === 'center') { x = 0; y = 0; }
    if (ins.op === 'draw') {
      if (ins.in > 0) segs.push([x, y, x + ins.dx, y + ins.dy, ins.in]);
      x += ins.dx; y += ins.dy;
    }
    pc += ins.len;
  }
  throw new Error(`AVG routine at $${start.toString(16)} never returned`);
}

const jsrList = (avg, addr, max) => {
  const out = [];
  for (let a = addr; avg.get(a)?.op === 'jsr' && out.length < max; a += 2) out.push(runAvg(avg, avg.get(a).target).segs);
  return out;
};

export function buildRom({ mem, avg, glyphs, strings }) {
  const SHAPES = {};
  for (let id = 0; id < 44; id++) {
    const s = readShape(mem, id);
    if (s) SHAPES[shapeName(id)] = s;
  }
  const OBSTACLES = [];
  for (let i = 0; mem.get(0x3fcc + i * 2) !== 0xff && i < 32; i++) {
    OBSTACLES.push({
      type: mem.get(0x3fcc + i * 2),
      facing: (mem.get(0x3fcd + i * 2) / 256) * TAU,
      x: sword(mem, 0x76ab + i * 2),
      z: sword(mem, 0x7681 + i * 2),
    });
  }
  const GLYPHS = Object.fromEntries(glyphs.map((g) => [g.char, runAvg(avg, g.target).segs]));
  const VG = {
    reticle1: runAvg(avg, 0x34cc),
    reticle2: runAvg(avg, 0x3500),
    radar: runAvg(avg, 0x353c),
    life: runAvg(avg, 0x3590),
    cracks: jsrList(avg, 0x36f8, 16),
    landscape: jsrList(avg, 0x3006, 8),
  };
  return { SHAPES, OBSTACLES, GLYPHS, VG, STRINGS: strings };
}

async function main() {
  const file = process.argv[2];
  const html = file ? readFileSync(file, 'utf8') : await (await fetch(LISTING_URL)).text();
  const rom = buildRom(parseListing(toText(html)));
  const body = Object.entries(rom).map(([k, v]) => `export const ${k} = ${JSON.stringify(v)};`).join('\n');
  writeFileSync(new URL('../src/data/rom.js', import.meta.url), `// GENERATED by tools/extract-rom.mjs from ${LISTING_URL}. Do not edit.\n${body}\n`);
  console.log(`shapes ${Object.keys(rom.SHAPES).length}, obstacles ${rom.OBSTACLES.length}, glyphs ${Object.keys(rom.GLYPHS).length}, strings ${rom.STRINGS.length}, cracks ${rom.VG.cracks.length}, landscape ${rom.VG.landscape.length}`);
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) main();
```

export const TAU = Math.PI * 2;
const WORLD = 65536; // 16-bit world coordinates wrap at ±32768

export const clamp = (v, lo, hi) => Math.min(hi, Math.max(lo, v));
export const wrapAngle = (a) => a - TAU * Math.floor((a + Math.PI) / TAU);
export const wrapCoord = (v) => v - WORLD * Math.floor((v + WORLD / 2) / WORLD);

export const delta = (ax, az, bx, bz) => [wrapCoord(bx - ax), wrapCoord(bz - az)];
export const dist = (ax, az, bx, bz) => Math.hypot(...delta(ax, az, bx, bz));
export function bearing(ax, az, bx, bz) {
  const [dx, dz] = delta(ax, az, bx, bz);
  return Math.atan2(dx, dz);
}

export function mulberry32(seed) {
  return () => {
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

import { OBSTACLES } from './data/rom.js';
import { PLAYER, ENEMY, RULES, MESSAGES } from './config.js';
import { wrapAngle, wrapCoord } from './math.js';
import { unitBlocked } from './world.js';

const MAX_DT = 0.05;

export function createGame({ rng = Math.random, obstacles = OBSTACLES, lives = RULES.lives } = {}) {
  return {
    rng, obstacles, lives,
    score: 0, enemyScore: 0, bonusIdx: 0, time: 0, over: false,
    player: { x: 0, z: 0, facing: 0, alive: true, deadFor: 0 },
    enemy: null, enemyDelay: ENEMY.spawnDelay, forceGround: false, missilesLaunched: 0,
    saucer: null, saucerDelay: rng() * ENEMY.saucer.delayMax,
    shells: [], debris: [],
    blockedFor: 0, jolt: 0, events: [],
  };
}

export function step(g, input, dt) {
  dt = Math.min(dt, MAX_DT);
  g.events = [];
  g.time += dt;
  g.blockedFor = Math.max(0, g.blockedFor - dt);
  g.jolt *= Math.exp(-dt * 12);
  if (g.over) return g.events;
  if (g.player.alive) movePlayer(g, input, dt);
  return g.events;
}

function movePlayer(g, input, dt) {
  const p = g.player;
  const forward = (input.left + input.right) / 2, turn = (input.left - input.right) / 2;
  p.facing = wrapAngle(p.facing + turn * PLAYER.turnRate * dt);
  if (!forward) return;
  const d = forward * PLAYER.speed * dt;
  const nx = wrapCoord(p.x + Math.sin(p.facing) * d), nz = wrapCoord(p.z + Math.cos(p.facing) * d);
  if (unitBlocked(g, nx, nz, p)) {
    if (g.blockedFor === 0) g.events.push({ type: 'blocked' });
    g.blockedFor = MESSAGES.blockedShow;
    g.jolt = Math.max(g.jolt, 0.5);
    return;
  }
  p.x = nx;
  p.z = nz;
}

```js
import { ENEMY, RULES } from './config.js';
import { TAU, clamp, wrapAngle, wrapCoord, bearing, dist } from './math.js';
import { obstacleAt, unitBlocked } from './world.js';

export function makeEnemy(kind, x, z, facing = 0) {
  return {
    kind, x, z, facing, goal: facing,
    y: kind === 'missile' ? ENEMY.missile.spawnAlt : 0,
    age: 0, aimTimer: 0, reverseFor: 0, zigSide: 1, zigTimer: 0, straight: false, treadPhase: 0,
  };
}

export function chooseKind(g) {
  if (!g.forceGround && g.score >= RULES.missileScore && g.rng() < 0.5) return 'missile';
  return g.missilesLaunched >= RULES.superAfterMissiles ? 'super' : 'tank';
}

export function spawnEnemy(g) {
  const kind = chooseKind(g), p = g.player;
  g.forceGround = false;
  const spread = g.score - g.enemyScore >= ENEMY.wideSpawnLead ? ENEMY.spawnSpreadWide : ENEMY.spawnSpreadNarrow;
  let x = 0, z = 0;
  for (let i = 0; i < 64; i++) {
    const d = ENEMY.spawnDist * (g.rng() < 0.5 ? 0.5 : 1);
    const b = p.facing + (g.rng() * 2 - 1) * spread;
    x = wrapCoord(p.x + Math.sin(b) * d);
    z = wrapCoord(p.z + Math.cos(b) * d);
    if (kind === 'missile' || !obstacleAt(g, x, z)) break;
  }
  if (kind !== 'missile') return makeEnemy(kind, x, z, g.rng() * TAU);
  g.missilesLaunched++;
  const e = makeEnemy(kind, x, z, bearing(x, z, p.x, p.z));
  e.straight = g.missilesLaunched === 1;
  return e;
}

export function updateEnemy(g, e, dt) {
  e.age += dt;
  return e.kind === 'missile' ? updateMissile(g, e, dt) : updateTank(g, e, dt, ENEMY[e.kind]);
}

function move(e, d) {
  e.x = wrapCoord(e.x + Math.sin(e.facing) * d);
  e.z = wrapCoord(e.z + Math.cos(e.facing) * d);
  e.treadPhase += d;
}

function updateTank(g, e, dt, cfg) {
  const p = g.player;
  const toPlayer = bearing(e.x, e.z, p.x, p.z), d = dist(e.x, e.z, p.x, p.z);
  const aggressive = g.score - g.enemyScore >= ENEMY.aggressiveLead || g.score >= RULES.alwaysAggressiveScore;
  e.aimTimer -= dt;
  if (e.aimTimer <= 0) {
    e.goal = aggressive || e.age >= ENEMY.homingAfter ? toPlayer : g.rng() * TAU;
    e.aimTimer = aggressive ? ENEMY.aggressiveReaim : 1 + g.rng() * 3;
  }
  const ox = e.x, oz = e.z, wasReversing = e.reverseFor > 0;
  if (wasReversing) {
    e.reverseFor -= dt;
    move(e, -cfg.speed * dt);
  } else {
    const err = wrapAngle(e.goal - e.facing);
    const aligned = Math.abs(err) <= ENEMY.aimTolerance;
    const rate = (aligned ? cfg.turnSlow : cfg.turnFast) * dt;
    e.facing = wrapAngle(e.facing + clamp(err, -rate, rate));
    if (d > cfg.standoff) move(e, (aligned ? 1 : 0.5) * cfg.speed * dt);
  }
  if (unitBlocked(g, e.x, e.z, e)) {
    e.x = ox;
    e.z = oz;
    if (wasReversing) e.reverseFor = 0;
    else {
      e.reverseFor = ENEMY.reverseFor;
      e.goal = g.rng() * TAU;
      e.aimTimer = ENEMY.reverseFor;
    }
  }
  return { fire: wantsToFire(g, e, toPlayer, d, aggressive), gone: false };
}

function wantsToFire(g, e, toPlayer, d, aggressive) {
  if (!g.player.alive || e.age < ENEMY.noFireFor) return false;
  if (Math.abs(wrapAngle(toPlayer - e.facing)) > ENEMY.aimTolerance) return false;
  return aggressive || e.age >= ENEMY.alwaysFireAfter || g.score >= ENEMY.fireAnyScore || d < ENEMY.closeRange;
}

function updateMissile(g, e, dt) {
  const m = ENEMY.missile, p = g.player;
  const toPlayer = bearing(e.x, e.z, p.x, p.z), d = dist(e.x, e.z, p.x, p.z);
  e.y = Math.max(0, e.y - m.fallRate * dt);
  let heading = toPlayer;
  if (!e.straight && d > m.zigStopDist) {
    e.zigTimer -= dt;
    if (e.zigTimer <= 0) {
      e.zigSide = -e.zigSide;
      e.zigTimer = m.zigFlip;
    }
    heading += e.zigSide * m.zigAmp * Math.min(1, e.age / m.zigRamp);
  }
  e.facing = wrapAngle(heading);
  move(e, m.speed * dt); // ponytail: missiles ignore obstacles (ROM hops low ones)
  return { fire: false, gone: d > ENEMY.missileReplaceDist };
}

export function updateSaucer(g, dt) {
  const cfg = ENEMY.saucer, s = g.saucer;
  if (!s) {
    if (g.score < cfg.minScore || !g.player.alive) return;
    g.saucerDelay -= dt;
    if (g.saucerDelay > 0) return;
    const b = g.rng() * TAU, d = 6000 + g.rng() * 14000;
    g.saucer = {
      x: wrapCoord(g.player.x + Math.sin(b) * d), z: wrapCoord(g.player.z + Math.cos(b) * d),
      y: 0, vx: 0, vz: 0, retarget: 0, spin: 0, dying: 0,
    };
    return;
  }
  if (s.dying > 0) {
    s.dying -= dt;
    if (s.dying <= 0) {
      g.saucer = null;
      g.saucerDelay = g.rng() * cfg.delayMax;
    }
    return;
  }
  s.retarget -= dt;
  if (s.retarget <= 0) {
    s.vx = (g.rng() * 2 - 1) * cfg.maxVel;
    s.vz = (g.rng() * 2 - 1) * cfg.maxVel;
    s.retarget = g.rng() * cfg.retargetMax;
  }
  s.x = wrapCoord(s.x + s.vx * dt);
  s.z = wrapCoord(s.z + s.vz * dt);
  s.spin += dt * 2;
}

import { OBSTACLES } from './data/rom.js';
import { PLAYER, SHELL, ENEMY, RULES, MESSAGES } from './config.js';
import { TAU, wrapAngle, wrapCoord, dist } from './math.js';
import { unitBlocked, shellHitsObstacle, randomClearSpot } from './world.js';
import { spawnEnemy, updateEnemy, updateSaucer } from './ai.js';

const MAX_DT = 0.05;
const GRAVITY = 6000;
const CHUNKS = {
  tank: ['chunk10', 'chunk11', 'chunk12', 'chunk13', 'chunk14', 'chunk15'],
  super: ['chunk10', 'chunk11', 'chunk12', 'chunk14', 'chunk15'],
  missile: ['chunk18', 'chunk19', 'chunk1a', 'chunk1b', 'chunk1c', 'chunk1d'],
};

export function createGame({ rng = Math.random, obstacles = OBSTACLES, lives = RULES.lives } = {}) {
  return {
    rng, obstacles, lives,
    score: 0, enemyScore: 0, bonusIdx: 0, time: 0, over: false,
    player: { x: 0, z: 0, facing: 0, alive: true, deadFor: 0 },
    enemy: null, enemyDelay: ENEMY.spawnDelay, forceGround: false, missilesLaunched: 0,
    saucer: null, saucerDelay: rng() * ENEMY.saucer.delayMax,
    shells: [], debris: [],
    blockedFor: 0, jolt: 0, events: [],
  };
}

export function step(g, input, dt) {
  dt = Math.min(dt, MAX_DT);
  g.events = [];
  g.time += dt;
  g.blockedFor = Math.max(0, g.blockedFor - dt);
  g.jolt *= Math.exp(-dt * 12);
  updateDebris(g, dt);
  if (g.over) return g.events;
  if (g.player.alive) {
    movePlayer(g, input, dt);
    if (input.fire) fireShell(g, g.player, 'player');
  } else updateDeath(g, dt);
  updateEnemySlot(g, dt);
  updateSaucer(g, dt);
  updateShells(g, dt);
  return g.events;
}

function movePlayer(g, input, dt) {
  const p = g.player;
  const forward = (input.left + input.right) / 2, turn = (input.left - input.right) / 2;
  p.facing = wrapAngle(p.facing + turn * PLAYER.turnRate * dt);
  if (!forward) return;
  const d = forward * PLAYER.speed * dt;
  const nx = wrapCoord(p.x + Math.sin(p.facing) * d), nz = wrapCoord(p.z + Math.cos(p.facing) * d);
  if (unitBlocked(g, nx, nz, p)) {
    if (g.blockedFor === 0) g.events.push({ type: 'blocked' });
    g.blockedFor = MESSAGES.blockedShow;
    g.jolt = Math.max(g.jolt, 0.5);
    return;
  }
  p.x = nx;
  p.z = nz;
}

function fireShell(g, u, owner) {
  if (g.shells.some((s) => s.owner === owner)) return;
  const sx = Math.sin(u.facing), sz = Math.cos(u.facing);
  g.shells.push({
    owner,
    x: wrapCoord(u.x + sx * SHELL.muzzle), z: wrapCoord(u.z + sz * SHELL.muzzle),
    vx: sx * SHELL.speed, vz: sz * SHELL.speed, life: SHELL.life,
  });
  g.events.push({ type: 'fire', owner });
}

function updateEnemySlot(g, dt) {
  if (!g.player.alive) return; // the world holds still while the windshield is cracked
  if (!g.enemy) {
    g.enemyDelay -= dt;
    if (g.enemyDelay <= 0) {
      g.enemy = spawnEnemy(g);
      g.events.push({ type: 'enemySpawn', kind: g.enemy.kind });
    }
    return;
  }
  const { fire, gone } = updateEnemy(g, g.enemy, dt);
  if (gone) {
    g.enemy = null;
    g.enemyDelay = 0;
    return;
  }
  if (fire) fireShell(g, g.enemy, 'enemy');
  const e = g.enemy, m = ENEMY.missile;
  if (e.kind === 'missile' && e.y < m.hittableBelow && dist(e.x, e.z, g.player.x, g.player.z) < m.contactRadius) {
    spawnDebris(g, e);
    g.enemy = null;
    killPlayer(g);
  }
}

function updateShells(g, dt) {
  g.shells = g.shells.filter((s) => {
    s.life -= dt;
    if (s.life <= 0) return false;
    const n = Math.ceil((SHELL.speed * dt) / SHELL.maxSubstep), h = dt / n;
    for (let i = 0; i < n; i++) {
      s.x = wrapCoord(s.x + s.vx * h);
      s.z = wrapCoord(s.z + s.vz * h);
      if (shellHitsObstacle(g, s.x, s.z)) {
        g.events.push({ type: 'shellBurst', x: s.x, z: s.z });
        return false;
      }
      if (s.owner === 'player') {
        const e = g.enemy;
        if (e && dist(s.x, s.z, e.x, e.z) < ENEMY.hitRadius && (e.kind !== 'missile' || e.y < ENEMY.missile.hittableBelow)) {
          destroyEnemy(g);
          return false;
        }
        const u = g.saucer;
        if (u && !(u.dying > 0) && dist(s.x, s.z, u.x, u.z) < ENEMY.hitRadius) {
          u.dying = ENEMY.saucer.fade;
          addScore(g, ENEMY.saucer.score);
          g.events.push({ type: 'saucerHit' });
          return false;
        }
      } else if (g.player.alive && dist(s.x, s.z, g.player.x, g.player.z) < PLAYER.hitRadius) {
        killPlayer(g);
        return false;
      }
    }
    return true;
  });
}

function destroyEnemy(g) {
  const e = g.enemy;
  addScore(g, ENEMY[e.kind].score);
  spawnDebris(g, e);
  g.events.push({ type: 'enemyDestroyed', kind: e.kind, x: e.x, z: e.z });
  g.enemy = null;
  g.enemyDelay = ENEMY.spawnDelay;
}

function addScore(g, points) {
  g.score += points;
  while (g.bonusIdx < RULES.bonusAt.length && g.score >= RULES.bonusAt[g.bonusIdx]) {
    g.bonusIdx++;
    g.lives++;
    g.events.push({ type: 'bonusTank', big: g.bonusIdx === RULES.bonusAt.length });
  }
}

function killPlayer(g) {
  const p = g.player;
  p.alive = false;
  p.deadFor = 0;
  g.lives--;
  g.enemyScore += RULES.enemyKillBonus;
  g.jolt = 1;
  g.shells = [];
  g.events.push({ type: 'playerHit' });
}

function updateDeath(g, dt) {
  const p = g.player;
  p.deadFor += dt;
  if (p.deadFor < RULES.deathPause) return;
  if (g.lives <= 0) {
    g.over = true;
    g.events.push({ type: 'gameOver' });
    return;
  }
  Object.assign(p, randomClearSpot(g), { facing: g.rng() * TAU, alive: true, deadFor: 0 });
  g.enemy = null; // a live enemy is replaced; a missile becomes a ground unit
  g.forceGround = true;
  g.enemyDelay = ENEMY.respawnHold;
}

function spawnDebris(g, e) {
  for (const shape of CHUNKS[e.kind]) {
    g.debris.push({
      shape, x: e.x, y: e.y, z: e.z,
      vx: (g.rng() - 0.5) * 3000, vy: 1500 + g.rng() * 2500, vz: (g.rng() - 0.5) * 3000,
      facing: g.rng() * TAU, spin: (g.rng() - 0.5) * 8, life: 2,
    });
  }
}

function updateDebris(g, dt) {
  g.debris = g.debris.filter((d) => {
    d.life -= dt;
    d.vy -= GRAVITY * dt;
    d.x = wrapCoord(d.x + d.vx * dt);
    d.y = Math.max(0, d.y + d.vy * dt);
    d.z = wrapCoord(d.z + d.vz * dt);
    d.facing += d.spin * dt; // ROM chunks spin about Y only
    return d.life > 0;
  });
}

import { clamp } from './math.js';

export const treadsFromArcade = (forward, turn) => ({
  left: clamp(forward + turn, -1, 1),
  right: clamp(forward - turn, -1, 1),
});

const DEADZONE = 0.2;

export function createInput(win = window) {
  const down = new Set();
  const prev = { fire: false, start: false, toggle: false, fullscreen: false };
  let mode = 'arcade';
  win.addEventListener('keydown', (e) => {
    down.add(e.code);
    if (e.code.startsWith('Arrow') || e.code === 'Space') e.preventDefault();
  });
  win.addEventListener('keyup', (e) => down.delete(e.code));
  win.addEventListener('blur', () => down.clear());
  const k = (code) => (down.has(code) ? 1 : 0);
  const edge = (name, held) => {
    const hit = held && !prev[name];
    prev[name] = held;
    return hit;
  };

  return {
    get mode() { return mode; },
    read() {
      let { left, right } =
        mode === 'arcade'
          ? treadsFromArcade(
              Math.max(k('KeyW'), k('ArrowUp')) - Math.max(k('KeyS'), k('ArrowDown')),
              Math.max(k('KeyD'), k('ArrowRight')) - Math.max(k('KeyA'), k('ArrowLeft')),
            )
          : { left: k('KeyQ') - k('KeyA'), right: k('KeyP') - k('KeyL') };
      let fire = down.has('Space'), start = down.has('Enter');
      const pad = Array.from(globalThis.navigator?.getGamepads?.() ?? []).find(Boolean);
      if (pad) {
        const axis = (i) => (Math.abs(pad.axes[i] ?? 0) < DEADZONE ? 0 : -pad.axes[i]);
        if (axis(1) || axis(3)) [left, right] = [axis(1), axis(3)];
        fire ||= [0, 5, 7].some((i) => pad.buttons[i]?.pressed);
        start ||= !!pad.buttons[9]?.pressed;
      }
      if (edge('toggle', down.has('KeyT'))) mode = mode === 'arcade' ? 'treads' : 'arcade';
      return {
        left, right,
        fire: edge('fire', fire),
        start: edge('start', start),
        fullscreen: edge('fullscreen', down.has('KeyF')),
      };
    },
  };
}

export function createLineBuffer(max = 32768) {
  const data = new Float32Array(max * 5);
  return {
    data,
    count: 0,
    push(x0, y0, x1, y1, intensity) {
      if (this.count >= max) return;
      const o = this.count++ * 5;
      data[o] = x0; data[o + 1] = y0; data[o + 2] = x1; data[o + 3] = y1; data[o + 4] = intensity;
    },
    clear() { this.count = 0; },
  };
}

  vec2 n = vec2(-dir.y, dir.x);
  vec2 p = mix(a - dir * halfW, b + dir * halfW, corner.x) + n * (corner.y * halfW);
  vP = p; vSeg = seg; vI = inten;
  gl_Position = vec4(p.x / res.x * 2.0 - 1.0, 1.0 - p.y / res.y * 2.0, 0.0, 1.0);
}`;

const LINE_FS = `#version 300 es
precision highp float;
in vec2 vP;
in vec4 vSeg;
in float vI;
uniform float sigma;
out vec4 o;
void main() {
  vec2 pa = vP - vSeg.xy, ba = vSeg.zw - vSeg.xy;
  float h = clamp(dot(pa, ba) / max(dot(ba, ba), 0.0001), 0.0, 1.0);
  float d = length(pa - ba * h);
  o = vec4(exp(-d * d / (2.0 * sigma * sigma)) * vI, 0.0, 0.0, 1.0);
}`;

const FULL_VS = `#version 300 es
out vec2 uv;
void main() {
  vec2 p = vec2((gl_VertexID << 1) & 2, gl_VertexID & 2);
  uv = p;
  gl_Position = vec4(p * 2.0 - 1.0, 0.0, 1.0);
}`;

const DECAY_FS = `#version 300 es
precision highp float;
in vec2 uv;
uniform sampler2D prev, fresh;
uniform float decay;
out vec4 o;
void main() { o = texture(prev, uv) * decay + texture(fresh, uv) * (1.0 - decay); }`;

const BLUR_FS = `#version 300 es
precision highp float;
in vec2 uv;
uniform sampler2D src;
uniform vec2 dir;
out vec4 o;
void main() {
  vec4 c = texture(src, uv) * 0.227027;
  c += (texture(src, uv + dir * 1.384615) + texture(src, uv - dir * 1.384615)) * 0.316216;
  c += (texture(src, uv + dir * 3.230769) + texture(src, uv - dir * 3.230769)) * 0.070270;
  o = c;
}`;

const OUT_FS = `#version 300 es
precision highp float;
in vec2 uv;
uniform sampler2D glow, bloom;
uniform float bloomK, redLine;
uniform vec2 res;
uniform vec3 green, red;
out vec4 o;
void main() {
  float v = texture(glow, uv).r + texture(bloom, uv).r * bloomK;
  vec3 tint = (1.0 - uv.y) * res.y < redLine ? red : green;
  o = vec4(1.0 - exp(-v * tint * 2.0), 1.0);
}`;

export function createVectorRenderer(canvas, opts = {}) {
  const o = {
    lineHalfWidth: 5, sigma: 1.4, persistence: 0.035, bloom: 1.6, redLinePx: 216,
    green: [0.25, 1.0, 0.35], red: [1.0, 0.22, 0.18], maxLines: 32768, ...opts,
  };
  const gl = canvas.getContext('webgl2', { antialias: false, alpha: false });
  if (!gl) throw new Error('WebGL2 is unavailable');
  const floatOk = !!gl.getExtension('EXT_color_buffer_float');
  const W = canvas.width, H = canvas.height;

  const compile = (type, src) => {
    const s = gl.createShader(type);
    gl.shaderSource(s, src);
    gl.compileShader(s);
    if (!gl.getShaderParameter(s, gl.COMPILE_STATUS)) throw new Error(gl.getShaderInfoLog(s));
    return s;
  };
  const program = (vs, fs) => {
    const p = gl.createProgram();
    gl.attachShader(p, compile(gl.VERTEX_SHADER, vs));
    gl.attachShader(p, compile(gl.FRAGMENT_SHADER, fs));
    gl.linkProgram(p);
    if (!gl.getProgramParameter(p, gl.LINK_STATUS)) throw new Error(gl.getProgramInfoLog(p));
    const u = {};
    for (let i = 0; i < gl.getProgramParameter(p, gl.ACTIVE_UNIFORMS); i++) {
      const { name } = gl.getActiveUniform(p, i);
      u[name] = gl.getUniformLocation(p, name);
    }
    return { p, u };
  };
  const target = (w, h) => {
    const tex = gl.createTexture();
    gl.bindTexture(gl.TEXTURE_2D, tex);
    gl.texImage2D(gl.TEXTURE_2D, 0, floatOk ? gl.RGBA16F : gl.RGBA8, w, h, 0, gl.RGBA, floatOk ? gl.HALF_FLOAT : gl.UNSIGNED_BYTE, null);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
    const fb = gl.createFramebuffer();
    gl.bindFramebuffer(gl.FRAMEBUFFER, fb);
    gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, tex, 0);
    return { tex, fb, w, h };
  };

  const lines = program(LINE_VS, LINE_FS), decay = program(FULL_VS, DECAY_FS);
  const blur = program(FULL_VS, BLUR_FS), out = program(FULL_VS, OUT_FS);
  const fresh = target(W, H), glow = [target(W, H), target(W, H)];
  const halfA = target(W / 2, H / 2), halfB = target(W / 2, H / 2);

  const lineVao = gl.createVertexArray();
  gl.bindVertexArray(lineVao);
  gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([0, -1, 1, -1, 0, 1, 1, 1]), gl.STATIC_DRAW);
  gl.enableVertexAttribArray(0);
  gl.vertexAttribPointer(0, 2, gl.FLOAT, false, 0, 0);
  const inst = gl.createBuffer();
  gl.bindBuffer(gl.ARRAY_BUFFER, inst);
  gl.bufferData(gl.ARRAY_BUFFER, o.maxLines * 20, gl.DYNAMIC_DRAW);
  gl.enableVertexAttribArray(1);
  gl.vertexAttribPointer(1, 4, gl.FLOAT, false, 20, 0);
  gl.vertexAttribDivisor(1, 1);
  gl.enableVertexAttribArray(2);
  gl.vertexAttribPointer(2, 1, gl.FLOAT, false, 20, 16);
  gl.vertexAttribDivisor(2, 1);
  const fullVao = gl.createVertexArray();
  let cur = 0;

  const fullscreen = (prog, dst, textures, setUniforms) => {
    gl.bindFramebuffer(gl.FRAMEBUFFER, dst ? dst.fb : null);
    gl.viewport(0, 0, dst ? dst.w : W, dst ? dst.h : H);
    gl.useProgram(prog.p);
    textures.forEach(([name, t], i) => {
      gl.activeTexture(gl.TEXTURE0 + i);
      gl.bindTexture(gl.TEXTURE_2D, t.tex);
      gl.uniform1i(prog.u[name], i);
    });
    setUniforms?.(prog.u);
    gl.bindVertexArray(fullVao);
    gl.drawArrays(gl.TRIANGLES, 0, 3);
  };

  return {
    draw(buf, dt) {
      const n = Math.min(buf.count, o.maxLines);
      gl.bindFramebuffer(gl.FRAMEBUFFER, fresh.fb);
      gl.viewport(0, 0, W, H);
      gl.clearColor(0, 0, 0, 1);
      gl.clear(gl.COLOR_BUFFER_BIT);
      gl.useProgram(lines.p);
      gl.uniform2f(lines.u.res, W, H);
      gl.uniform1f(lines.u.halfW, o.lineHalfWidth);
      gl.uniform1f(lines.u.sigma, o.sigma);
      gl.bindVertexArray(lineVao);
      gl.bindBuffer(gl.ARRAY_BUFFER, inst);
      gl.bufferSubData(gl.ARRAY_BUFFER, 0, buf.data, 0, n * 5);
      gl.enable(gl.BLEND);
      gl.blendFunc(gl.ONE, gl.ONE);
      gl.drawArraysInstanced(gl.TRIANGLE_STRIP, 0, 4, n);
      gl.disable(gl.BLEND);

      const prev = glow[cur], next = glow[1 - cur];
      cur = 1 - cur;
      fullscreen(decay, next, [['prev', prev], ['fresh', fresh]], (u) => gl.uniform1f(u.decay, Math.exp(-dt / o.persistence)));
      fullscreen(blur, halfA, [['src', next]], (u) => gl.uniform2f(u.dir, 2 / W, 0));
      fullscreen(blur, halfB, [['src', halfA]], (u) => gl.uniform2f(u.dir, 0, 2 / H));
      fullscreen(out, null, [['glow', next], ['bloom', halfB]], (u) => {
        gl.uniform1f(u.bloomK, o.bloom);
        gl.uniform1f(u.redLine, o.redLinePx);
        gl.uniform2f(u.res, W, H);
        gl.uniform3fv(u.green, o.green);
        gl.uniform3fv(u.red, o.red);
      });
    },
  };
}
```

import { SHAPES, VG } from '../data/rom.js';
import { VIEW, MODEL_Y_SCALE, BG } from '../config.js';
import { TAU, wrapCoord } from '../math.js';

const OBSTACLE_SHAPES = { 0: 'narrowPyramid', 1: 'tallBox', 12: 'widePyramid', 15: 'shortBox' };
const ENEMY_SHAPES = { tank: 'tank', super: 'superTank', missile: 'missile' };
const AVG_PX = VIEW.height / 768; // ROM screen units → pixels

export function makeCamera(x, z, facing, jolt = 0) {
  return { x, z, facing, sin: Math.sin(facing), cos: Math.cos(facing), horizonY: VIEW.height / 2 + jolt * VIEW.joltPx };
}

function toView(cam, wx, wy, wz) {
  const dx = wrapCoord(wx - cam.x), dz = wrapCoord(wz - cam.z);
  return [dx * cam.cos - dz * cam.sin, wy, dx * cam.sin + dz * cam.cos];
}

const fade = (z) => Math.max(0.35, Math.min(1, 1.15 - z / 30000));

function segment(buf, cam, a, b, bright) {
  let [ax, ay, az] = a, [bx, by, bz] = b;
  const n = VIEW.near;
  if (az < n && bz < n) return;
  if (az < n) { const t = (n - az) / (bz - az); ax += (bx - ax) * t; ay += (by - ay) * t; az = n; }
  if (bz < n) { const t = (n - bz) / (az - bz); bx += (ax - bx) * t; by += (ay - by) * t; bz = n; }
  const f = VIEW.focal, cx = VIEW.width / 2, hy = cam.horizonY;
  buf.push(cx + (ax * f) / az, hy - (ay * f) / az, cx + (bx * f) / bz, hy - (by * f) / bz, bright * fade(Math.min(az, bz)));
}

export function inView(cam, x, z) {
  const [vx, , vz] = toView(cam, x, 0, z);
  return vz > VIEW.near && vz < VIEW.far && Math.abs(vx) < (vz * VIEW.width) / 2 / VIEW.focal;
}

export function drawModel(buf, cam, shape, x, y, z, facing, bright = 1) {
  const cz = toView(cam, x, 0, z)[2];
  if (cz < -4000 || cz > VIEW.far) return;
  const s = Math.sin(facing), c = Math.cos(facing);
  const v = shape.verts.map(([lx, ly, lz]) => toView(cam, x + lx * c + lz * s, y + ly * MODEL_Y_SCALE, z - lx * s + lz * c));
  for (const [i, j, inten] of shape.segs) segment(buf, cam, v[i], v[j], (bright * inten) / VIEW.modelIntensity);
}

// Landscape: 8 sections of 512 AVG units = 4096 per full turn, scrolled by facing.
export function drawBackground(buf, cam, dt) {
  const W = VIEW.width, hy = cam.horizonY;
  buf.push(0, hy, W, hy, 0.8);
  const scroll = (cam.facing / TAU) * 4096 + BG.phase;
  VG.landscape.forEach((segs, i) => {
    let base = (((i * 512 - scroll) % 4096) + 4096) % 4096;
    if (base > 2048) base -= 4096;
    for (const [x0, y0, x1, y1, inten] of segs) {
      buf.push(W / 2 + (base + x0) * AVG_PX, hy - (y0 + BG.yOffset) * AVG_PX, W / 2 + (base + x1) * AVG_PX, hy - (y1 + BG.yOffset) * AVG_PX, inten / 12);
    }
  });
}

export function drawWorld(buf, g, cam) {
  for (const o of g.obstacles) drawModel(buf, cam, SHAPES[OBSTACLE_SHAPES[o.type]], o.x, 0, o.z, o.facing);
  const e = g.enemy;
  if (e) drawModel(buf, cam, SHAPES[ENEMY_SHAPES[e.kind]], e.x, e.y, e.z, e.facing);
  const s = g.saucer;
  if (s) drawModel(buf, cam, SHAPES.saucer, s.x, s.y, s.z, s.spin, s.dying > 0 ? s.dying / 2 : 1);
  for (const sh of g.shells) drawModel(buf, cam, SHAPES.shell, sh.x, 0, sh.z, Math.atan2(sh.vx, sh.vz));
  for (const d of g.debris) drawModel(buf, cam, SHAPES[d.shape], d.x, d.y, d.z, d.facing, Math.min(1, d.life));
}

import { VG, GLYPHS, STRINGS } from '../data/rom.js';
import { VIEW, RADAR, MESSAGES, HUD, ENEMY } from '../config.js';
import { wrapAngle, bearing, delta } from '../math.js';

const S = VIEW.height / 768, CX = VIEW.width / 2, CY = VIEW.height / 2;

export function drawAvg(buf, segs, ox = 0, oy = 0, scale = 1, bright = 1) {
  for (const [x0, y0, x1, y1, i] of segs) {
    buf.push(CX + (ox + x0 * scale) * S, CY - (oy + y0 * scale) * S, CX + (ox + x1 * scale) * S, CY - (oy + y1 * scale) * S, (bright * i) / 12);
  }
}

// ROM strings are drawn at half glyph size: 24-unit advance × 0.5.
export function drawText(buf, text, x, y, bright = 1, scale = 0.5) {
  for (const ch of text) {
    if (GLYPHS[ch]) drawAvg(buf, GLYPHS[ch], x, y, scale, bright);
    x += 24 * scale;
  }
}

export function say(buf, prefix, text) {
  const s = STRINGS.find((e) => e.text.startsWith(prefix));
  if (s) drawText(buf, text ?? s.text, s.x, s.y);
}

export function relativeView(player, x, z) {
  const [dx, dz] = delta(player.x, player.z, x, z), c = Math.cos(player.facing), s = Math.sin(player.facing);
  return [dx * c - dz * s, dx * s + dz * c];
}

export function radarBlip(player, target) {
  const [rx, rz] = relativeView(player, target.x, target.z);
  if (Math.hypot(rx, rz) > RADAR.range) return null;
  const k = RADAR.radiusUnits / RADAR.range;
  return [rx * k, rz * k];
}

export function enemyDirection(player, target) {
  const rel = wrapAngle(bearing(player.x, player.z, target.x, target.z) - player.facing);
  if (Math.abs(rel) >= MESSAGES.rearAngle) return 'REAR';
  if (rel >= MESSAGES.sideAngle) return 'RIGHT';
  if (rel <= -MESSAGES.sideAngle) return 'LEFT';
  return null;
}

export function enemyInRange(player, target) {
  const [rx, rz] = relativeView(player, target.x, target.z);
  return rz > 0 && Math.abs(rx) < (rz * VIEW.width) / 2 / VIEW.focal && Math.hypot(rx, rz) < RADAR.range;
}

export function onTarget(player, target) {
  const [rx, rz] = relativeView(player, target.x, target.z);
  return rz > 0 && rz < RADAR.range && Math.abs(rx) < ENEMY.hitRadius;
}

export function sweepCrossed(from, to, angle) {
  const span = wrapAngle(to - from), off = wrapAngle(angle - from);
  return span > 0 && off > 0 && off <= span;
}

export const createHudState = () => ({ sweep: 0, blip: null, blipGlow: 0 });

export function updateHudState(h, g, dt) {
  const next = h.sweep + RADAR.sweepRate * dt;
  h.blip = g.enemy && g.player.alive ? radarBlip(g.player, g.enemy) : null;
  h.blipGlow = Math.max(0, h.blipGlow - dt * 1.5);
  let pinged = false;
  if (h.blip && sweepCrossed(h.sweep, next, Math.atan2(h.blip[0], h.blip[1]))) {
    h.blipGlow = 1;
    pinged = true;
  }
  h.sweep = wrapAngle(next);
  return pinged;
}

export function drawHud(buf, g, h, highScore, t) {
  const p = g.player, blinkOn = Math.floor(t * MESSAGES.blinkHz * 2) % 2 === 0;
  say(buf, 'SCORE', `SCORE ${String(g.score).padStart(8)}`);
  say(buf, 'HIGH SCORE ', `HIGH SCORE ${String(highScore).padStart(8)}`);
  for (let i = 0; i < g.lives; i++) drawAvg(buf, VG.life.segs, HUD.livesX + i * HUD.livesSpacing, HUD.livesY);

  drawAvg(buf, VG.radar.segs);
  const [rx, ry] = VG.radar.end, r = RADAR.radiusUnits;
  drawAvg(buf, [[0, 0, Math.sin(h.sweep) * r, Math.cos(h.sweep) * r, 8]], rx, ry);
  if (h.blip) drawAvg(buf, [[h.blip[0], h.blip[1], h.blip[0], h.blip[1], 4 + 11 * h.blipGlow]], rx, ry);

  if (g.enemy && p.alive) {
    if (enemyInRange(p, g.enemy)) say(buf, 'ENEMY IN RANGE');
    const dir = enemyDirection(p, g.enemy);
    if (dir && blinkOn) say(buf, 'ENEMY TO', `ENEMY TO ${dir}`);
  }
  if (g.blockedFor > 0) say(buf, 'MOTION BLOCKED');
  if (p.alive) drawAvg(buf, (g.enemy && onTarget(p, g.enemy) ? VG.reticle2 : VG.reticle1).segs);
  else VG.cracks.slice(0, Math.floor(p.deadFor * 24) + 1).forEach((segs) => drawAvg(buf, segs));
  if (g.over) say(buf, 'GAME OVER');
}

const NOTE = (midi) => 440 * 2 ** ((midi - 69) / 12);
// ponytail: approximated 9-note 1812 Overture fanfare; check against arcade footage of the 100K bonus and retune.
const FANFARE = [[67, 0.15], [67, 0.15], [67, 0.15], [72, 0.3], [71, 0.15], [72, 0.15], [74, 0.3], [76, 0.3], [79, 0.6]];

export function createAudio() {
  let ctx = null, master, noise, engine, saucer, missile;

  function drone(type, freq, cutoff, lfoHz = 0, lfoDepth = 0) {
    const osc = ctx.createOscillator(), lp = ctx.createBiquadFilter(), gain = ctx.createGain();
    osc.type = type;
    osc.frequency.value = freq;
    lp.frequency.value = cutoff;
    gain.gain.value = 0;
    osc.connect(lp).connect(gain).connect(master);
    if (lfoHz) {
      const lfo = ctx.createOscillator(), depth = ctx.createGain();
      lfo.frequency.value = lfoHz;
      depth.gain.value = lfoDepth;
      lfo.connect(depth).connect(osc.frequency);
      lfo.start();
    }
    osc.start();
    return { osc, gain };
  }

  function tone(type, freq, at, dur, vol, endFreq = freq) {
    const t = ctx.currentTime + at, osc = ctx.createOscillator(), g = ctx.createGain();
    osc.type = type;
    osc.frequency.setValueAtTime(freq, t);
    osc.frequency.exponentialRampToValueAtTime(endFreq, t + dur);
    g.gain.setValueAtTime(vol, t);
    g.gain.exponentialRampToValueAtTime(0.001, t + dur);
    osc.connect(g).connect(master);
    osc.start(t);
    osc.stop(t + dur);
  }

  function burst(dur, vol, fromHz, toHz) {
    const t = ctx.currentTime, src = ctx.createBufferSource(), lp = ctx.createBiquadFilter(), g = ctx.createGain();
    src.buffer = noise;
    lp.frequency.setValueAtTime(fromHz, t);
    lp.frequency.exponentialRampToValueAtTime(toHz, t + dur);
    g.gain.setValueAtTime(vol, t);
    g.gain.exponentialRampToValueAtTime(0.001, t + dur);
    src.connect(lp).connect(g).connect(master);
    src.start(t);
    src.stop(t + dur);
  }

  const SOUNDS = {
    fire: (e) => {
      const v = e.owner === 'player' ? 0.9 : 0.3;
      burst(0.4, v, 3500, 250);
      tone('triangle', 160, 0, 0.25, v * 0.6, 45);
    },
    shellBurst: () => burst(0.3, 0.25, 1800, 200),
    enemyDestroyed: () => burst(1.4, 0.8, 2500, 90),
    saucerHit: () => { burst(1.0, 0.6, 3000, 300); tone('sine', 900, 0, 1.0, 0.3, 200); },
    playerHit: () => burst(2.2, 1.0, 5000, 60),
    blocked: () => tone('square', 160, 0, 0.25, 0.25, 70),
    enemySpawn: () => [0, 1, 2].forEach((i) => tone('sine', 300, i * 0.18, 0.1, 0.3)),
    bonusTank: (e) => (e.big ? SOUNDS.fanfare() : [0, 1, 2, 3].forEach((i) => tone('square', 880, i * 0.16, 0.09, 0.2))),
    radarPing: () => tone('sine', 1250, 0, 0.07, 0.12),
    fanfare: () => {
      let at = 0;
      for (const [n, d] of FANFARE) { tone('square', NOTE(n), at, d * 0.9, 0.2); at += d; }
    },
  };

  const set = (d, vol, freq) => {
    d.gain.gain.setTargetAtTime(vol, ctx.currentTime, 0.05);
    if (freq) d.osc.frequency.setTargetAtTime(freq, ctx.currentTime, 0.1);
  };

  return {
    unlock() {
      if (ctx) { if (ctx.state === 'suspended') ctx.resume(); return; }
      ctx = new AudioContext();
      master = ctx.createGain();
      master.gain.value = 0.5;
      master.connect(ctx.destination);
      noise = ctx.createBuffer(1, ctx.sampleRate * 2, ctx.sampleRate);
      const d = noise.getChannelData(0);
      for (let i = 0; i < d.length; i++) d[i] = Math.random() * 2 - 1; // ponytail: white noise; a 12 kHz LFSR would add arcade grit
      engine = drone('sawtooth', 30, 260);
      saucer = drone('sine', 600, 4000, 7, 180);
      missile = drone('square', 90, 900, 18, 30);
    },
    handle(events) {
      if (!ctx) return;
      for (const e of events) SOUNDS[e.type]?.(e);
    },
    update({ on, engine: level = 0, saucer: s = false, missile: m = false }) {
      if (!ctx) return;
      set(engine, on ? 0.08 + 0.1 * level : 0, 30 + 28 * level);
      set(saucer, on && s ? 0.08 : 0);
      set(missile, on && m ? 0.1 : 0);
    },
  };
}

const KEY = 'battlezone.highscores';

export const DEFAULT_SCORES = ['EDR', 'MPH', 'JED', 'DES', 'TKE', 'VKB', 'EL', 'HAD', 'ORR', 'GJR'].map((initials) => ({ score: 5000, initials }));

export function rankFor(table, score) {
  const i = table.findIndex((e) => score > e.score);
  return i === -1 ? (table.length < 10 && score > 0 ? table.length : -1) : i;
}

export function insertScore(table, score, initials) {
  const i = rankFor(table, score);
  return i < 0 ? table : [...table.slice(0, i), { score, initials }, ...table.slice(i)].slice(0, 10);
}

export function loadScores(storage = globalThis.localStorage) {
  try {
    const t = JSON.parse(storage.getItem(KEY));
    if (Array.isArray(t) && t.length && t.every((e) => Number.isFinite(e.score) && typeof e.initials === 'string')) return t;
  } catch {
    // private mode, blocked storage, or corrupt JSON: fall through to defaults
  }
  return DEFAULT_SCORES;
}

export function saveScores(table, storage = globalThis.localStorage) {
  try {
    storage.setItem(KEY, JSON.stringify(table));
  } catch {
    // storage unavailable: scores last for this session only
  }
}
